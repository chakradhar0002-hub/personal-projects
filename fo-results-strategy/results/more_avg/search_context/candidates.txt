BASELINE (B00, reference, not a candidate)
  Universe: in_fo results (events.csv in_fo; 2 blanks filled from fa_panel in_fo), as in
  fo-results-strategy/pattern_tests/winners_rsi/rebuild/rebuild.py.
  k = events.i_react. XN = (stock adj return on k - Nifty 50 return on k)*100. Winner: XN > 4.
  RSI14 = Wilder RSI(14) on the stock's own adjusted traded closes (adjusted_ohlcv), as-of last traded close <= i_cut.
  Signal: XN > 4 and RSI14(cut) > 50. Tradable: return on k exists, session k+21 exists, <= 2 blank daily returns k+1..k+21.
  Trade: buy close k, sell close k+20, short Nifty 50 same value.
  vsN_net = (prod(1+r_{k+1..k+20}) - 1 - (N_{k+20}/N_k - 1))*100 - 0.19 (blank r = 0). raw_net = stock*100 - 0.17.
  Every candidate below = baseline signal AND one extra filter. Entry / exit / hedge / costs unchanged.

FEATURES (all computed from data up to and including the close of k; nothing later)
  N = Nifty 50 close (index_close.csv 'Nifty 50'), sessions indexed by sessions.csv i.
  nifty_sma50_up   : N[k] > mean(N[k-49..k])
  nifty_sma200_up  : N[k] > mean(N[k-199..k])
  nifty_r20        : (N[k]/N[k-20] - 1)*100
  vix              : index_close 'India VIX' close at session k
  S = the stock's sector index (events.sector_index) close. If S has a NaN at k, or fewer than 50 valid closes in
      k-49..k, or a NaN at k-20, the feature uses 'Nifty 500' instead (fallback; flagged sec_fallback).
  sec_sma50_up     : S[k] > mean(S[k-49..k])
  sec_r20          : (S[k]/S[k-20] - 1)*100
  sec_rel20        : sec_r20 - nifty_r20
  breadth_w        : among in_fo results of the same qn with i_react < k (strictly earlier reaction days) and a
                     non-missing XN: share with XN > 4. NaN if fewer than 10 such earlier results (NaN fails every
                     breadth filter).
  season_pos       : (number of in_fo results of the same qn with i_react < k) / (number of in_fo results in that qn).
                     The denominator is the F&O list size for the season (every F&O company reports each quarter), known
                     at the start of the season.
  fin              : fa_panel.fin_type (fallback events.fin_type) in {'Bank', 'NBFC / financial'}.
  TERCILES: cut points t1 (33.33rd pct) and t2 (66.67th pct) of the feature over the DISCOVERY baseline signals
  (tradable baseline signals with qn 0..13; NaN values ignored). Low = x <= t1, Mid = t1 < x <= t2, High = x > t2.
  Cut points are computed from features only (no outcomes) and appended below before any outcome is computed.
