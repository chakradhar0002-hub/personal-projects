PRE-REGISTRATION - TRADE A (pre-results 3-day window) x PAST PERFORMANCE
Written 2026-10-09 BEFORE any outcome of trade A (outcomes.csv three_day, placebo three_day) was loaded or computed.
Only feature distributions of panel.csv (no outcome columns) were looked at, to check counts.

------------------------------------------------------------------------------------------------------------------------
1. TRADE, UNIVERSE, OUTCOME
------------------------------------------------------------------------------------------------------------------------
Universe: the 3,280 F&O results in perf/features/panel.csv (in_fo True), qn 0 (Results for Jan-Mar 2021, Q4 FY21) to
  qn 21 (Results for Apr-Jun 2026, Q1 FY27). Rows with missing three_day are dropped from everything.
Trade: buy the cutoff close (i_cut = 2 sessions before the result session), sell the Day+1 close (i_p1).
  y = three_day (outcomes.csv, %). LONG rule P&L = y; SHORT rule P&L = -y. Net = P&L - 0.17.
Decision time: the cutoff close. Only *_A columns, lag21, vol_ratio_5_60 and point-in-time ranks computed at i_cut are
  used. XN, W and every *_B column are NOT used (they contain the current reaction day).
Halves: first 14 quarters = qn 0-13 (Results for Jan-Mar 2021 .. Apr-Jun 2024); last 8 = qn 14-21 (Results for Jul-Sep
  2024 .. Apr-Jun 2026).

Quintile definitions (all point in time):
  Track-record quintiles: percentile rank (pandas rank pct) of the feature among the same quarter's F&O results that have
    the feature. Top quintile = pct > 0.80, bottom = pct <= 0.20. Track-record features use only earlier results whose
    windows ended before the cutoff (asserted in the panel build); every earlier result of the quarter's stocks is
    complete before that quarter's season starts, so these within-quarter ranks use no future information.
  Price-performance quintiles: percentile rank (0-100, 100 = best) among the same quarter's F&O stocks, ALL measured on
    this row's cutoff session (panel rank_vsN_63/126/252_A; rank_vsN_21, rank_vsSec_63 and rank_vsSec_252 are computed
    the same way in build_signals.py and the method is validated by reproducing rank_vsN_63/126/252_A exactly).
    Top = rank > 80, bottom = rank <= 20.

3. STATISTICS PER TEST
------------------------------------------------------------------------------------------------------------------------
 n; avg = mean P&L (gross, signed by direction); net = avg - 0.17; excess = avg minus the quarter-matched average of all
 F&O results (sum over quarters of n_q x quarter mean, signed, / n); quarters with net avg > 0 / quarters with trades;
 avg, net and excess in the first 14 and last 8 quarters (with n); net avg without the 5 best (signed) trades.
 LUCK p (one-sided in the stated direction): within-quarter permutation of three_day among all F&O results of that quarter
   (= random same-size per-quarter picks from all F&O results), B = 20,000, seed 20261009. p = (1 + #{perm >= obs})/(1+B).
 HOLM: Holm step-down on the 33 luck p values.
 FAMILY-WISE maxT: same 20,000 permutations applied jointly to all 33 tests (keeps their overlap); z = (stat - perm mean)
   / perm sd, signed; single-step maxT adjusted p = (1 + #{max_k z*_k >= z_j}) / (1 + B).
 PLACEBO (every test that can be evaluated off results; all 33): the same signal on ordinary stock-days =
   ta/build/placebo_ta.csv.gz rows with in_fo True and a next result (qn_next 0-21, symbol+qn_next in the panel): days
   with no result session within [k-9, k+13]; outcome = 3-day forward return k -> k+3 (three_day there).
   Price-performance features are recomputed at day k with the same definitions; ranks are among the F&O stocks of
   quarter qn_next measured on day k; dist_52wh = placebo_ta dist_52w_high_pct. Track-record flags are those of the
   stock's next result (symbol, qn_next), whose history ended before k; for TR15/TR16 (drift) only days k after the
   previous result's drift exit (i_react + 20) count.
   Placebo excess = signal-day mean minus the quarter-matched mean of all placebo days (same quarter weights as the
   results trades). DiD = results excess - placebo excess. Placebo p = P(placebo excess of a random draw of placebo
   signal days with the trades' per-quarter counts >= results excess), 10,000 draws, seed 7. Trades in quarters with no
   placebo signal day are left out of this comparison (qn 0 has no placebo days).

A test WORKS only if ALL of:
 (a) better in both halves: excess > 0 in the first 14 AND in the last 8 quarters, and net avg > 0 in both halves;
 (b) Holm p < 0.10 (33-test family);
 (c) beats its placebo: DiD > 0 and placebo p < 0.10;
 (d) holds without its best 5 trades: net avg without the 5 best trades > 0.
 maxT p < 0.10 is reported as a secondary family-wise check.

------------------------------------------------------------------------------------------------------------------------

 Same statistics as section 3 (luck p, Holm within the 3, placebo using placebo_ta lag_pct / vol_ratio_5_60), plus
 overlap with the 85 original trades, and comparison with the filter left alone (RP1 vs volume >= 1.0 alone; RP2 and
 RP3 vs lag < -10 alone): difference and a permutation p (one-sided, 20,000 label shuffles within the 'filter alone'

 A replacement CAN REPLACE only if it meets the same four criteria (a)-(d) (Holm within the 3) AND its average is at
